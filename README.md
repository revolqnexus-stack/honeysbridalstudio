# Honey's Bridal Studio - Premium React Application

A luxury, award-winning bridal makeup studio website built with React, TypeScript, Tailwind CSS, and Framer Motion.

## 🎨 Features

- **Premium Design System** - Sophisticated color palette, typography, and spacing
- **Smooth Animations** - Framer Motion animations throughout, 60fps performance
- **Lenis Smooth Scrolling** - Buttery smooth scroll experience
- **Fully Responsive** - Perfect on all devices from mobile to desktop
- **Mobile-First Navigation** - Elegant fullscreen mobile menu with staggered animations
- **Optimized Performance** - Lazy loading, code splitting, optimized assets
- **Modern Architecture** - Clean component structure, custom hooks, TypeScript
- **Accessibility** - Semantic HTML, ARIA labels, keyboard navigation

## 🚀 Tech Stack

- **React 19** - Latest React with concurrent features
- **TypeScript** - Type-safe development
- **Vite** - Lightning-fast build tool
- **Tailwind CSS** - Utility-first styling
- **Framer Motion** - Production-ready animations
- **Lenis** - Smooth scroll library
- **GSAP** - Advanced animations (where needed)
- **Lucide React** - Beautiful icon system

## 📦 Installation

```bash
npm install
```

## 🏃‍♂️ Development

```bash
npm run dev
```

Open [http://localhost:5174](http://localhost:5174) in your browser.

## 🏗️ Build

```bash
npm run build
```

## 🎭 Animation Details

All animations follow these principles:
- 60fps performance
- Easing: cubic-bezier(0.25, 1, 0.5, 1)
- Staggered reveals for groups
- Scroll-based triggers
- Respects `prefers-reduced-motion`
